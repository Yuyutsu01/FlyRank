## 2. How These Materials Guide Portfolio Construction

When prompting Claude during subsequent build weeks:
1. **Identity Kit (`style-note.md`)**: Enforces strict styling restraint. Claude will keep CSS minimal, preventing unnecessary third-party libraries, excessive gradients, or generic neon "AI startup" clichés.
2. **Case Studies (`portfolio_cases.md`)**: Provides the exact 3-beat narrative structure (**Problem → What I Did → What Came Of It**) and verified empirical numbers (e.g., AEGIS ROC-AUC 0.912, ResearchMind 94.2% factual precision, FlyRank 3.08x baseline lift) so AI outputs never invent fake achievements.
3. **Content Map (`content_map.md`)**: Directs page layout flow, ensuring that the strongest work leads, each page has an explicit named CTA, and every section connects back to the primary action: *"Explore my work."*
