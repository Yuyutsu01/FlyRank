## 1. Assignment Objective

The objective of this assignment is to make a deliberate, reasoned technology stack decision for Shivam Sharma's AI/ML research and engineering portfolio through explicit constraints, concrete trade-offs, and rigorous pressure testing—avoiding unexamined AI recommendations.

---

## 2. Decision Summary

| Aspect | Decision | Rationale |
|---|---|---|
| **Chosen Stack** | **Next.js + Vercel (No Backend Initially)** | Component modularity, clean multi-page routing, markdown integration, and fast static export without backend operational overhead. |
| **Option 1 Rejected** | Plain HTML + CSS + JS (GitHub Pages) | Low scalability; copy-pasting layouts and navigation across multi-page case studies creates high development friction. |
| **Option 3 Rejected** | Next.js + Vercel + Backend API | Unnecessary operational fragility (free-tier cold starts, CORS, serverless timeouts) for a capability hiring managers do not require. |
| **Cost** | **₹0 ($0)** | Fully supported by Vercel Hobby Free Tier with zero hidden costs. |
| **Two-Week Feasibility** | **Confirmed** | Achievable in 7–10 days using modular components and locked content maps. |
| **Backend Need** | **No** | All projects are proven via empirical data, SVG charts, loss curves, and GitHub repositories. |
